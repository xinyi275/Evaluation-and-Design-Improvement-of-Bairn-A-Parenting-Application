# Evaluation and Design Improvement of Bairn: A Parenting Application
This repository contains supplementary research materials for the evaluation and design improvement of the Bairn parenting application.

## Contents

### 1. Interview Protocol

The semi-structured interview protocol used for the Bairn user evaluation, including the interview objectives, interview questions, and related interview content.

### 2. Thematic Coding

The final themes developed through thematic analysis of the interview data.

The complete coding dataset and interview transcripts are not included in this public repository because they are derived from participant interview data and may contain potentially identifiable or sensitive information. Only the final themes are provided to demonstrate the outcome of the thematic analysis while protecting participant confidentiality.

### 3. Design Implications

The design implications developed from the findings of the Bairn user evaluation. These implications demonstrate how the user needs and problems identified in the study were translated into specific directions for improving the Bairn design.
